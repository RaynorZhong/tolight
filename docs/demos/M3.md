## 本地入口

    scripts/release-check.sh
    scripts/release-check.sh --production --tag v0.1.0
    target/debug/tolight check-security --source public

普通release-check检查本地结构与版本，并如实列出阻塞；结构无误但外部Gate未完成时，本地模式退出0，production模式退出2。结构错误退出1。它不连接数据库，不发送消息，不修改Git索引/引用，不授权发布。报告/说明只在显式传输出路径时以0600独占创建。

source-rehearsal默认把源码白名单复制到.local/source-rehearsal.*/，只在自己0700目录建立一次性Gitfixture和本地演练tag，按精确SHA克隆，运行真正的SQLX_OFFLINE=true cargo build --locked --workspace及两个二进制help；依赖缓存可共享，target独立。prepare-only只返回prepared/built=false，不冒充构建通过。原用户仓库、现有预览和数据库不受影响；这不等于已公开发布或二进制逐字节可复现。
